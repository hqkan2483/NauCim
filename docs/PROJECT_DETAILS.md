# Документация project-details.html

## Описание

`project-details.html` — главная страница приложения Nautilus.CIM для визуализации и управления информационными моделями (CIM). Страница отображает иерархическую структуру проектов, моделей, профилей, пакетов и элементов классов с поддержкой интерактивного исследования деталей.

## Структура страницы

### 1. Основной контейнер

```html
<div class="app-container">
  <!-- SIDEBAR -->
  <!-- MAIN CONTENT -->
</div>
```

### 2. Боковая панель (Sidebar)

#### Элементы:

- **Кнопка раскрытия** (`sidebar-toggle`) — скрывает/показывает боковую панель
- **Заголовок проекта** (`sidebar-project-title`) — название текущего проекта
- **Навигация** (`sidebar-nav`) — меню и структура проекта
- **Структура проекта** (`current-project-structure`) — дерево проектов, моделей и профилей

### 3. Основной контент (Main Content)

#### Компоненты:

- **Toolbar** — панель инструментов с названием проекта и кнопками действий
- **Content Area** — основная область с несколькими контейнерами:
  - `no-project-warning` — предупреждение об отсутствии проекта
  - `models-container` — список моделей и их детали
  - `profiles-container` — список профилей и их детали
  - `item-container` — детали выбранного элемента (пакет, класс, атрибут, связь)

### 4. Модальные окна

- **new-model-modal** — форма добавления новой модели
- **new-project-modal** — форма создания нового проекта

## Основные функции

### Инициализация

#### `document.addEventListener("DOMContentLoaded", async () => {...})`

Запускается при загрузке страницы:

1. Загружает данные `await loadSampleData()`
2. Обновляет информацию о проекте
3. Проверяет выбранный проект
4. Рендерит структуру проекта
5. Восстанавливает состояние боковой панели из `localStorage`

---

### Управление проектами

#### `updateSidebarTitle()`

Обновляет заголовок боковой панели с названием текущего проекта.

**Параметры:** нет  
**Возвращает:** void

#### `updatePageTitle()`

Обновляет заголовок главной страницы.

**Параметры:** нет  
**Возвращает:** void

#### `checkProject()`

Проверяет наличие выбранного проекта и отображает соответствующий контент:

- Если проект не выбран — показывает предупреждение
- Если проект выбран — отображает модели и профили

**Параметры:** нет  
**Возвращает:** void

---

### Рендеринг структуры проекта

#### `renderCurrentProjectStructure()`

Отображает полную иерархическую структуру проекта в боковой панели:

- Проект (с кнопкой раскрытия)
  - Модели (со своей иерархией пакетов)
  - Профили (со своей иерархией пакетов)

**Параметры:** нет  
**Возвращает:** void

**Вызывает:**

- `renderModelTree()` для каждой модели
- `renderProfileTree()` для каждого профиля
- `initializeTreeExpanders()` для подключения обработчиков событий

---

### Рендеринг моделей

#### `renderModelTree(model, level = 0, baseId = "")`

Отображает модель с иконкой раскрытия и её корневыми пакетами.

**Параметры:**

- `model` — объект модели из `data.js`
- `level` — уровень вложенности (не используется в этой функции)
- `baseId` — уникальный идентификатор для состояния раскрытия

**Возвращает:** HTML-строка с деревом модели

**Структура дерева:**

```
🔷 Модель
  ├─ 📦 Корневой пакет 1
  │  ├─ 📁 Подпакет 1
  │  │  └─ 📄 Класс
  │  └─ 📄 Класс
  └─ 📦 Корневой пакет 2
```

---

#### `renderRootPackageTree(rootPkg, level = 0, baseId = "", modelId = null)`

Отображает корневой пакет модели.

**Параметры:**

- `rootPkg` — корневой пакет
- `level` — уровень вложенности
- `baseId` — идентификатор состояния
- `modelId` — идентификатор модели (для контекста)

**Возвращает:** HTML-строка

**Вызывает:**

- `renderElementTree()` для элементов (классов)
- `renderPackageTree()` для вложенных пакетов

---

#### `renderPackageTree(pkg, level = 0, baseId = "", modelId = null)`

Рекурсивно отображает вложенные пакеты.

**Параметры:**

- `pkg` — пакет
- `level` — уровень вложенности
- `baseId` — идентификатор состояния
- `modelId` — идентификатор модели

**Возвращает:** HTML-строка

**Вызывает самого себя** для вложенных пакетов

---

#### `renderElementTree(elem, level = 0, baseId = "", modelId = null)`

Отображает элемент (класс) с его атрибутами и связями.

**Параметры:**

- `elem` — элемент (класс)
- `level` — уровень вложенности
- `baseId` — идентификатор состояния
- `modelId` — идентификатор модели

**Возвращает:** HTML-строка

**Структура элемента:**

```
📄 Класс (abstract)
  ├─ 🔹 Атрибут1: String [1]
  ├─ 🔹 Атрибут2: Integer [0..1]
  ├─ 🔼 наследуется от ИмяКласса
  └─ → связь_с_классом [0..*]
```

---

#### `renderLinkItem(link)`

Отображает связь (ассоциацию или обобщение) между классами.

**Параметры:**

- `link` — объект связи с полями:
  - `relation_kind` — тип связи ("Generalization" или "Association")
  - `role` — роль ("child" или "parent")
  - `target_class_name` — имя целевого класса
  - `multiplicity` — мультиплексность [0..1], [1], [0..*] и т.д.

**Возвращает:** HTML-строка

**Иконки:**

- `🔼` — Generalization (обобщение)
- `→` — Association (ассоциация)

**Примеры:**

- `🔼 наследуется от BaseClass` (role: "child")
- `🔼 родитель для DerivedClass` (role: "parent")
- `→ связь_с_классом [0..*]`

---

### Рендеринг профилей

#### `renderProfileTree(profile, level = 0, baseId = "")`

Отображает профиль с его корневыми пакетами и атрибутами.

**Параметры:**

- `profile` — объект профиля
- `level` — уровень вложенности
- `baseId` — идентификатор состояния

**Возвращает:** HTML-строка

**Источник данных:**

- `profile.rootPackages` — загружается из `./models-data/profile-test.json`
- `profile.attributes` — дополнительные атрибуты профиля

**Структура дерева:**

```
⚡ Профиль
  ├─ 🗂️ Модель (корневой пакет)
  │  ├─ 📦 Пакет
  │  │  └─ 📄 Класс
  │  └─ 📄 Класс
  └─ • Атрибут профиля
```

---

#### `renderProfileRootPackageTree(rootPkg, level = 0, baseId = "", profileId = null)`

Отображает корневой пакет профиля.

**Параметры:**

- `rootPkg` — корневой пакет
- `level` — уровень вложенности
- `baseId` — идентификатор состояния
- `profileId` — идентификатор профиля

**Возвращает:** HTML-строка

**Иконка типа:**

- `🗂️` — Model (корневой элемент)
- `📦` — Package (обычный пакет)

---

#### `renderProfilePackageTree(pkg, level = 0, baseId = "", profileId = null)`

Рекурсивно отображает вложенные пакеты в профиле.

**Параметры:**

- `pkg` — пакет
- `level` — уровень вложенности
- `baseId` — идентификатор состояния
- `profileId` — идентификатор профиля

**Возвращает:** HTML-строка

---

#### `renderProfileElementTree(elem, level = 0, baseId = "", profileId = null)`

Отображает элемент (класс) в профиле с его атрибутами и связями.

**Параметры:**

- `elem` — элемент (класс)
- `level` — уровень вложенности
- `baseId` — идентификатор состояния
- `profileId` — идентификатор профиля

**Возвращает:** HTML-строка

**Дополнения:**

- Поддержка значений по умолчанию (`attr.default`)
- Таблица с типами иконок для разных типов элементов

### Управление состоянием дерева

#### `toggleTreeItem(itemId)`

Переключает состояние раскрытия элемента дерева.

**Параметры:**

- `itemId` — уникальный идентификатор элемента (строка)

**Возвращает:** void

**Сохранение:**

- Состояние сохраняется в `localStorage.expandedTreeItems`
- При переключении вызывает `renderCurrentProjectStructure()` для перерисовки

**Пример Id:**

- `model-1-0` — первая модель проекта 1
- `model-1-0-pkg-0` — первый пакет модели
- `profile-1-0` — первый профиль проекта 1

---

#### `toggleCurrentProjectStructure(projectId)`

Переключает состояние раскрытия структуры всего проекта.

**Параметры:**

- `projectId` — идентификатор проекта (число)

**Возвращает:** void

**Сохранение:**

- Состояние сохраняется в `localStorage.expandedProjects`

---

#### `initializeTreeExpanders()`

Подключает обработчики клика ко всем кнопкам раскрытия дерева.

**Параметры:** нет  
**Возвращает:** void

**Обработчики:**

- Для кнопок `.tree-expand-btn` — вызывает `toggleTreeItem(itemId)`
- Для кнопки `.project-expand-btn` — вызывает `toggleCurrentProjectStructure(projectId)`

**Важно:** должна вызваться ПОСЛЕ рендеринга `renderCurrentProjectStructure()`

### Управление элементами дерева

### Рендеринг деталей элемента

#### `renderItemDetails(itemId, itemType)`

Отображает подробную информацию о выбранном элементе (пакет или класс).

**Параметры:**

- `itemId` — идентификатор элемента
- `itemType` — тип элемента ("package", "element", "attribute", "link")

**Возвращает:** void

**Поиск:**

1. Сначала ищет в моделях через `findItemInModel()`
2. Если не найдено и тип "profile" — ищет в профилях

**Для атрибутов и связей:**

- Отображает родительский элемент (класс), в котором они находятся

**Макет для Package:**

- Название
- Описание (оригинальное)
- Описание (русское)
- Дополнительная информация

**Макет для Element (Class):**

- Название
- Флаг "Абстрактный класс"
- Стереотип
- Описание (оригинальное)
- Описание (русское)
- Дополнительная информация
- Таблица атрибутов:
  - Имя, Тип, Мультиплексность, Описание
- Таблица связей:
  - Имя связи, Тип связи, Класс назначения, Мн, Описание

**CSS-классы:**

- `.item-details-grid` — двухколонная сетка
- `.item-section` — разделы с таблицами
- `.table-bordered` — таблица с границами

---

#### `findItemInModel(model, itemId, itemType)`

Ищет элемент внутри модели и её пакетов.

**Параметры:**

- `model` — объект модели
- `itemId` — идентификатор элемента
- `itemType` — тип элемента

**Возвращает:** объект элемента или `null`

**Поиск в:**

1. Корневые пакеты модели
2. Через `findItemInPackage()` для каждого пакета

---

#### `findItemInPackage(pkg, itemId, itemType)`

Рекурсивно ищет элемент внутри пакета и его вложенных пакетов.

**Параметры:**

- `pkg` — пакет
- `itemId` — идентификатор элемента
- `itemType` — тип элемента

**Возвращает:**

- Для элемента: `{ item: elem, parent: null }`
- Для атрибута/связи: `{ item: attr/link, parent: elem }` (возвращает родителя для отображения полной информации)
- `null` — если не найдено

**Поиск в:**

1. Элементы пакета (классы)
2. Атрибуты элементов
3. Связи элементов
4. Вложенные пакеты (рекурсивно)

### Управление модальными окнами

#### `createModel()`

Создаёт новую модель и добавляет её в проект.

**Параметры:** нет  
**Возвращает:** void

**Поля формы:**

- `model-name` — название модели (обязательное)
- `model-type` — тип модели
- `model-desc` — описание
- `model-classes` — количество классов
- `model-attributes` — количество атрибутов

**Действия:**

1. Проверяет выбранный проект
2. Проверяет название
3. Вызывает `addModel()` из `data.js`
4. Закрывает модальное окно
5. Очищает форму
6. Перерисовывает список моделей

### Вспомогательные функции

#### `switchTab(tabName)`

Переключает активную вкладку в детальном представлении.

**Параметры:**

- `tabName` — имя вкладки ("properties", "structure", "stats", "xsd")

**Возвращает:** void

**Действия:**

1. Удаляет класс `active` со всех вкладок
2. Удаляет класс `active` со всего контента
3. Добавляет класс `active` к нажатой вкладке
4. Показывает соответствующий контент

---

Открывает страницу диаграммы классов для выбранной модели.

**Параметры:** нет  
**Возвращает:** void

**URL:** `diagram.html?model=ModelName`

**Проверка:** показывает alert, если модель не выбрана

---

Вспомогательная функция для рендеринга простого дерева элементов.

**Параметры:**

- `items` — массив элементов с полями `name`, `type`, `children`, `stereotype`
- `level` — текущий уровень вложенности

**Возвращает:** HTML-строка

---

#### `escapeHtml(text)`

Экранирует HTML-спецсимволы в тексте.

**Параметры:**

- `text` — текст для экранирования

## Хранилище (localStorage)

### `expandedTreeItems`

Сохраняет состояние раскрытия элементов дерева.

**Формат:** JSON объект с парами `itemId: true`

**Пример:**

```json
{
  "model-1-0": true,
  "model-1-0-pkg-0": true,
  "profile-1-0": true
}
```

### `expandedProjects`

Сохраняет состояние раскрытия проектов.

**Формат:** JSON объект с парами `projectId: true`

- `getModels(projectId)` — получить модели проекта
- `getModel(projectId, modelId)` — получить конкретную модель

## Примеры использования

### Выбрать модель программно

```javascript
selectModel(2, "TC57CIM - CIM100");
```

### Переключить вкладку

```javascript
switchTab("stats");
```

### Раскрыть элемент дерева

```javascript
toggleTreeItem("model-1-0-pkg-0");
```

### Получить выбранные элементы

```javascript
console.log(selectedModelId); // 2
console.log(selectedModelName); // "TC57CIM - CIM100"
console.log(selectedProfileId); // 4
console.log(selectedProfileName); // "GOST-58651.2"
```

## Обработка ошибок

- Если проект не найден — показывается предупреждение
- Если модель/профиль не выбраны — показывается alert
- Если элемент не найден — отображается "Элемент не найден"
- Если данные не загружены — показывается пустой список

## Производительность

### Оптимизации

- Использование `localStorage` для сохранения состояния
- Ленивый рендеринг дерева (только видимые элементы развёрнуты)
- Event delegation для обработки кликов на кнопки
- Переиспользование HTML-строк вместо DOM-манипуляций

### Потенциальные узкие места

- Большое дерево может замедлить рендеринг
- Сложные модели с тысячами классов требуют оптимизации
- Рекурсивный поиск в глубоком дереве может быть медленным
