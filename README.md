# Nautilus.CIM - Интерактивный прототип

## Описание

Кликабельный прототип платформы Nautilus.CIM для создания, редактирования и управления
профилями информационных моделей электроэнергетических систем по стандарту CIM.

## Структура файлов

```
NauCIM/
├── index.html          # Главная страница
├── projects.html       # Управление проектами
├── models.html         # Модели
├── profiles.html       # Профили
├── compare.html        # Сравнение профилей
├── diagram.html        # Редактор диаграмм
├── styles.css          # Единые стили
├── data.js             # Управление данными
└── README.md           # Инструкция
```

## Как использовать

1. Распакуйте архив в любую папку
2. Откройте файл index.html в браузере (Chrome, Firefox, Safari, Edge)
3. Начните работу с панели управления

## Основные функции

✅ Создание и управление проектами
✅ Импорт и просмотр моделей CIM
✅ Создание профилей на основе моделей
✅ Сравнение профилей
✅ Визуализация структуры классов
✅ Генерация XSD кода
✅ Древовидная навигация
✅ Поиск и фильтрация

## Примечания

- Все данные хранятся в localStorage браузера
- В архиве уже есть демо-данные (2 проекта, 3 модели, 4 профиля)
- Для полноценной работы требуется современный браузер с поддержкой ES6+

## Технические детали

### Технологии

- **HTML5** - структура страниц
- **CSS3** - стили и анимации
- **JavaScript ES6+** - логика и интерактивность
- **SVG** - отрисовка связей между классами
- **Drag and Drop API** - перетаскивание элементов
- **localStorage** - хранение данных локально

### Совместимость

- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

### Ограничения

- Нет серверной части - все данные хранятся локально
- При очистке кэша браузера данные удаляются
- Нет экспорта в другие форматы (пока)

Прототип разработан на основе концепции **Nautilus.CIM v0.0.3** для демонстрации функциональности платформы.

# Nautilus.CIM v2.0 - Интерактивный прототип с редактором диаграмм

## 🎉 Новые возможности

### 📐 Редактор диаграмм классов (diagram.html)

**Полнофункциональный визуальный редактор для создания UML-диаграмм классов:**

- ✅ **Drag-and-drop** - перетаскивайте классы из левой панели на холст
- ✅ **Два типа связей:**
  - ◁ **Наследование** (обобщение) - полая треугольная стрелка
  - → **Ассоциация** - простая стрелка
- ✅ **Интерактивное редактирование:**
  - Перемещение классов с автоматическим обновлением связей
  - 4 точки соединения на каждом классе (сверху, снизу, слева, справа)
  - Удаление классов через кнопку ×
- ✅ **Сеточный холст** для точного позиционирования
- ✅ **Панорамирование** средней кнопкой мыши
- ✅ **Сохранение** диаграмм в localStorage

## Примеры использования

### Создание иерархии классов

1. Добавьте родительский класс (например, `IdentifiedObject`)
2. Добавьте дочерние классы (например, `PowerSystemResource`, `AssetInfo`)
3. Переключитесь в режим **◁ Наследование**
4. Соедините дочерние классы с родительским
5. Получится классическая UML-иерархия с полыми стрелками

### Создание ассоциаций

1. Добавьте два связанных класса
2. Переключитесь в режим **→ Ассоциация**
3. Соедините классы
4. Простая стрелка покажет направление ассоциации
